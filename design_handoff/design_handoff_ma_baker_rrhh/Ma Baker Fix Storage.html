🔐 Fix: Permitir Subir Documentos

Error detectado:

new row violates row-level security policy

Esto significa que el bucket documentos no permite uploads desde el navegador. Hay que agregar políticas de acceso público.

1

Copia el SQL

Click en "Copiar SQL". Es el SQL que arregla las políticas del bucket.

-- ═══════════════════════════════════════════════
-- Permitir uploads/lecturas públicas en bucket "documentos"
-- ═══════════════════════════════════════════════

-- Hacer el bucket PÚBLICO (lectura)
UPDATE storage.buckets
SET public = true
WHERE id = 'documentos';

-- Eliminar políticas viejas (por si existen)
DROP POLICY IF EXISTS "public_upload" ON storage.objects;
DROP POLICY IF EXISTS "public_read" ON storage.objects;
DROP POLICY IF EXISTS "public_update" ON storage.objects;
DROP POLICY IF EXISTS "public_delete" ON storage.objects;

-- Política: cualquiera puede SUBIR a "documentos"
CREATE POLICY "public_upload" ON storage.objects
  FOR INSERT
  WITH CHECK (bucket_id = 'documentos');

-- Política: cualquiera puede LEER de "documentos"
CREATE POLICY "public_read" ON storage.objects
  FOR SELECT
  USING (bucket_id = 'documentos');

-- Política: cualquiera puede ACTUALIZAR (upsert)
CREATE POLICY "public_update" ON storage.objects
  FOR UPDATE
  USING (bucket_id = 'documentos');

-- Política: cualquiera puede ELIMINAR (cleanup)
CREATE POLICY "public_delete" ON storage.objects
  FOR DELETE
  USING (bucket_id = 'documentos');

-- Verificar políticas creadas
SELECT policyname, cmd
FROM pg_policies
WHERE tablename = 'objects' AND schemaname = 'storage';

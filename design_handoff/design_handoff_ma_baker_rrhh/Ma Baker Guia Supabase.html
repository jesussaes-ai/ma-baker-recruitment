Paso 3 — Crea la Tabla

Copia y pega el SQL en el editor, luego ejecútalo

1

Copia el siguiente SQL completo

Haz click en el botón 📋 Copiar SQL de abajo:

CREATE TABLE IF NOT EXISTS candidatos (
  id                         BIGSERIAL PRIMARY KEY,
  nombre                     TEXT,
  edad                       INTEGER,
  estatura                   NUMERIC,
  peso                       NUMERIC,
  genero                     TEXT,
  puesto_aplicado            TEXT,
  documentos                 JSONB DEFAULT '{}',
  requisitos_salud           JSONB DEFAULT '[]',
  respuestas_psicometricas   JSONB DEFAULT '{}',
  respuestas_tecnicas        JSONB DEFAULT '{}',
  puntaje_evaluacion_tecnica INTEGER,
  veredicto_final            TEXT,
  timestamp                  TIMESTAMPTZ,
  created_at                 TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE candidatos ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "allow_all" ON candidatos;
CREATE POLICY "allow_all" ON candidatos
  FOR ALL USING (true) WITH CHECK (true);
2

Pégalo en el editor de Supabase

Haz click dentro del editor de texto y presiona Ctrl + V (Windows) o Cmd + V (Mac).

3

Haz click en el botón verde "RUN ▶"

Está arriba a la derecha del editor. Al ejecutar verás el mensaje Success.
